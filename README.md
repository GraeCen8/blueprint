# blueprint

* a simple, fast, and easy to use tool to setup a new project *

### what can you do with blueprint?

when setting up a new project, you can use blueprint to:

* init the git repo
* setup language stuff (eg: rust, python, go)
* connect to a github repo
* add one of many base project templates (make your own!)
* set up a database if needed (postgres, sqlite, mysql)

### what is the difference between blueprint and other project setup tools?

* blueprint is a single binary that does everything
* other tools are more like a framework that you can use to build your own project setup tool rather than a single binary
* less code writing time
* less maintainance over base setup
* less code to maintain as our code is already battle tested
